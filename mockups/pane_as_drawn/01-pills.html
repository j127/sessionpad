sessionpad · the pane as the mod draws it

01 · Pills

The Desktop app draws every Button as a pill, so this direction leans on them: the open tab is the one black pill, note actions and the undo are grey ones. Grey shading groups the notes and stripes the timeline, and the accent is spent on one thing, the headline card. Each piece is drawn only with Box, Text, Button, Input and Markdown, the way each surface draws them.

Desktop app

the Code tab's side pane, 400px; follows light and dark

Desktop. Pills are the app's own Buttons, so their labels stay plain. The grey behind the notes and every other turn is promptBorder, and the undo row's pink is diffRemovedDimmed: the only fills that follow light and dark, so both modes keep them. Switch the palette and only the accent moves, the headline card's border and the branch mark; the open tab stays black in light mode and white in dark, whatever the accent.

Terminal

the same tree, 56 columns, always the dark terminal

Terminal. The tabs are plain buttons whose label is bold accent text, with the digit that presses them. The card is a round box-drawn frame, both shades become subtle (there is no soft pink in a terminal, so the words "Note deleted" carry the undo), and pills become [ label ]. Size, weight, mono and italic don't reach a terminal, and a margin is a whole line, so the pane runs taller.

Band above the prompt

the headline, one dim line

Band. The same line on both surfaces, dim, and cut at the end when the headline runs long. It is the one place the headline shows while the pane is shut.

Design notes — 01 · Pills

Direction

Pills, because the Desktop app already draws every Button as one. The open tab is the single primary pill, black in light mode and white in dark; the other tabs, the note actions, the edit field's save and its Cancel, Undo, Export and Refresh sizes are the default grey pill. Grouping comes from shading rather than borders: each note is a promptBorder rectangle, the deleted note leaves a diffRemovedDimmed row in its place, and the timeline stripes every other turn within each day. The accent is spent on the headline card's border and the branch-change mark, nothing else, so switching claude, merged or success changes only those.

What differs between the surfaces

  • Tabs. The mod branches on e.surface. On Desktop the open tab is a primary pill, because a styled Text inside a Button is ignored there. In a terminal, a primary button only turns its label blue, so the tabs are plain buttons whose label is bold accent text, with the digit hotkeys that work only while a terminal pane holds the keyboard.
  • Shading. promptBorder is a soft grey in both Desktop modes but a mid grey in a terminal that swallows dim text, so the note blocks and the turn stripes use subtle there. diffRemovedDimmed has no soft terminal form either, so the undo row is subtle too and its words say what happened.
  • Card and frame. The headline card's rounded border becomes a box-drawn ╭─╮ frame one cell wide, with the paddingX cell inside it.
  • Buttons and fields. Pills become [ label ], and the open tab, the one primary button, is a blue label rather than a black or white pill. The note field shows Note: Add a note… with no add button: Enter adds. The edit field is only its text, so [ save ] beside it is what says the note is being edited.
  • Timeline columns. Desktop stacks the time over the duration in one 10-cell column so the proportional summary keeps the width. The terminal puts them side by side in two 6-cell columns with one cell between, since a cell is cheap there and 10m41s fills six.
  • Type. Size, weight, mono and italic are Desktop only. In a terminal the headline, the day lines and "Other worktrees" read plain, and the aside is just dim. Passing bold on the terminal surface would get their emphasis back, if it's missed.
  • Inline code. Desktop's code chip is promptBorder too, so on a note it shows only as the mono face; in a terminal it's the accent color.
  • Height. marginTop={1} is 12px on Desktop and a whole line in a terminal, so the terminal Notes tab is about four lines taller per note.

Pills on grey

The app's grey pill is see-through: black at about 5% in light mode and white at about 15% in dark. On a note's promptBorder shade it draws a step darker in light mode and a step lighter in dark, so the Headline, Edit and Delete pills, and Cancel beside save, keep their shape in both modes. Undo does the same on the pink row.

Left out, because the pane can't draw it

  • Hover hints on the note buttons (they didn't show on Desktop and a terminal has no hover), icons, colored or bold pill labels, and raw tints that don't follow the mode.
  • Rules, rails or frames made of line characters on Desktop; the timeline's structure is Boxes and shading.
  • Right-aligned numbers: Text has no alignment, so durations and sizes sit left in their columns or at the end of a row.

Typography and palette of this page

The fonts, radius and density controls in the panel change only this page's chrome: the header, the captions and these notes. The frames keep their own fonts, because the Desktop app sets the pane in the system face and a terminal in its one monospace face. The chrome defaults to system-ui so it reads like the app around the pane; Georgia is there to set the notes apart from the frames. The three palettes are the theme keys the pane can take as its accent, and the page's own accent follows them.

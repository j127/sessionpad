Design notes — 01 · Segmented

Direction

Segmented treats the pane as a small native app. The tabs are a filled segmented control that can only be read as tabs, and every other part is a block of shade rather than a box of lines. Two kinds of block do all the work. Wells are a step darker than the pane in light mode and hold controls: the tab row, the note input and the undo strip. Cards are the surface color and hold content: each note, each day of turns, and the worktree facts. There is no outline anywhere inside the pane.

The accent appears only where something is current or primary: the open tab, the headline tint, the Add, Save and Undo buttons, a branch change, and the band's mark. Every action is a worded button, because hover tooltips don't work in the Desktop app.

Worktree facts Box (backgroundColor = surface) of rows: Box (row) holding a fixed-width dim Text label and a bold Text value. "measured 12:30" is dim. Then Button "Refresh sizes". Same; the mod cuts the path at its start ("…/") to fit the width.
Other worktrees A Box (backgroundColor = surface, row, space-between) per worktree: a column of bold branch Text over a dim path, then the size Text on the right. "measuring…" is italic dim; "size unavailable" is dim. Two lines per worktree, the size right-aligned on the first.
Band One dim Text line: an accent "◆", bold "pad:", then the headline. The same single line, cut with "…" at the end when it is too long: the full headline is one tab away.

Everything above is Box, Text, Button, Input and Markdown. There are no images, no icons beyond Unicode characters ("◆", "×", "→", "…"), no hover-only UI, no animation and no shadows. The mockup draws buttons soft-filled, and Add, Save and Undo filled with the accent, to show the intended emphasis. The host draws the Button itself: a native button in Desktop, [ label ] in a terminal. If the host can't tint a Button, the primary action still comes first in its group, and nothing else depends on the tint.

Two assumptions to check while building: the edit state needs the Input to start with the note's text, and the Desktop Input must sit flat inside its shaded Box.

Typography

  • System UI at 13.5px for the pane's text, one smaller step (11 to 12px) for meta lines, captions and chips, and one larger step (14.5px, bold) for the headline.
  • Hierarchy is carried by weight, dim, italic and background, which a terminal also has. Font size is Desktop-only polish, so the terminal loses nothing structural when every size flattens to one.
  • Captions ("Headline", "Notes (4)", "This worktree", "Other worktrees (3)") are small uppercase labels with wide letter spacing. In a terminal they become bold dim text.
  • Times, durations and sizes use tabular figures, so the time column lines up. In the Mono font they align by nature.
  • The Mono option (ui-monospace, SF Mono, Menlo) previews the terminal feel. No layout here depends on proportional widths, so it holds up. In this mockup inline code is a tinted run in the body font; the host's Markdown uses its own code font.

Palette

  • Clay (default) uses Claude Code's warm clay accent, darkened one step so white text on the open tab passes 4.5:1 contrast. The pane is a warm off-white and the text is near-black. In dark mode it becomes a warm charcoal close to a terminal's black, with a lighter clay and dark text on the accent.
  • Ocean (blue) and Moss (green) keep the same structure with a cooler or greener accent and a matching tinted neutral.
  • Every shade is mixed from the seven tokens with color-mix. Wells are 9% text mixed into the pane color, soft fills are 7% text mixed into the surface, tints are 9 to 14% accent mixed into the surface, and the accent ink on tinted chips is the accent pulled 25% toward the text color, so it keeps its contrast in both modes. That maps directly onto a terminal theme: a background, one step of background shade, the accent, and the warning color.
  • One extra tone, --tone-warn (ochre), colors the "stopped" chip; in a terminal it is the theme's warning color. It is yellower than Clay's orange accent, so "stopped" never reads as "current".
